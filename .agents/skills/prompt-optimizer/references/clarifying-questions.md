# Perguntas Clarificadoras por Tipo de Demanda

## Feature

```
1. O que essa feature faz exatamente? (objetivo)
2. Quem usa? (usuário/alvo)
3. Qual fluxo completo? (passo a passo)
4. Onde no sistema? (módulo, tela, endpoint)
5. Tem restrições? (tecnologia, performance, segurança)
```

## Bugfix

```
1. Qual bug exatamente? (descrição do problema)
2. Onde acontece? (tela, fluxo, endpoint)
3. Qual erro? (mensagem, status code, stack trace)
4. Como reproduzir? (passos)
5. O que já tentou? (tentativas anteriores)
```

## Refactor

```
1. O que refatorar? (arquivo, módulo, função)
2. Por quê? (problema atual: performance, legibilidade, manutenção)
3. Qual abordagem? (extrair classe, renomear, mover, etc.)
4. Tem dependências? (outros módulos que usam)
5. Como validar? (testes que devem continuar passando)
```

## Melhoria

```
1. O que melhorar? (componente específico)
2. Que tipo de melhoria? (performance, UX, segurança, código)
3. Métrica atual? (tempo, erros, satisfação)
4. Métrica esperada? (objetivo mensurável)
5. Restrições? (tempo, orçamento, compatibilidade)
```

## Template Genérico

```
**O que você quer fazer?**
{resposta}

**Onde no sistema?**
{resposta}

**Por que precisa fazer isso?**
{resposta}

**Tem algo que NÃO pode mudar?**
{resposta}

**Como vou saber que ficou pronto?**
{resposta}
```
